# XueKuiBangDownloader

本地项目名称：下载器。

处理学魁榜视频链接的 Windows 下载工具。

## 开发与运行

技术：VB.NET / .NET Framework 4.7.2。

入口：`学魁榜下载器.sln`。

使用安装了对应 SDK/工作负载的 Visual Studio 打开解决方案；较旧的工程可能需要兼容性调整。
